# AI 파이프라인 모니터

이 모니터는 회원가입과 클론 학습 과정 중 AI 파트가 담당하는 항목만 보여줍니다.

- AI API 및 음성 워커 프로세스 상태
- RAG 프로필 학습 및 완료 콜백 결과
- ElevenLabs 음성 학습 및 음성 유사도
- GPU 얼굴 워커, 얼굴 프로필 생성 및 얼굴 유사도
- 전체 클론 유사도와 구성요소별 점수
- GPU 메모리와 사용률

백엔드 애플리케이션 로그는 의도적으로 제외했습니다.

AI 구성요소 점수 4개가 모두 확인되면 운영 환경과 같은 계산식으로 예상 종합점수를 계산합니다.
점수가 모두 모이기 전에는 화면에 표시되는 종합점수를 `마지막 AI 점수 이벤트`로 구분합니다.
데이터베이스에 최종 저장된 점수는 백엔드의 값을 기준으로 합니다.

## Windows CMD에서 실행하기

저장소 최상위 경로에서 다음 명령을 실행합니다.

```bat
tools\monitor-ai-pipeline.cmd
```

옵션을 입력하지 않으면 AI 로그에서 가장 최근에 확인된 회원을 자동으로 추적합니다.
특정 회원만 계속 확인하려면 다음과 같이 회원 UUID를 지정합니다.

```bat
tools\monitor-ai-pipeline.cmd --user-uuid bb3fe728-136f-43d0-891b-9c4bd82e95be
```

GPU 서버를 새로 예약하면 SSH 포트가 바뀔 수 있습니다. 현재 포트가 `40053`이 아니라면
다음과 같이 포트를 지정합니다.

```bat
tools\monitor-ai-pipeline.cmd --gpu-port 40123
```

모니터를 종료하려면 `Ctrl+C`를 누릅니다. 화면을 계속 갱신하지 않고 현재 상태만 한 번
확인하려면 다음 명령을 사용합니다.

```bat
tools\monitor-ai-pipeline.cmd --once
```

## 상태 표시 의미

- `WAITING`: 아직 해당 작업의 이벤트가 도착하지 않은 상태
- `PROCESSING`: AI 작업이 진행 중인 상태
- `COMPLETED`: 작업이 정상적으로 완료된 상태
- `WARNING`: AI 작업은 끝났지만 완료 콜백과 같은 후속 처리가 정상적으로 전달되지 않은 상태
- `FAILED`: 작업 중 오류가 발생한 상태이며 해당 줄 아래에 오류 내용이 표시됨

구조화된 RAG 로그와 개선된 얼굴 완료 로그는 이번 변경 사항을 AI 서버와 GPU 서버에
배포한 이후의 작업부터 온전히 표시됩니다. 배포 이전 로그에서도 음성 상태와 일부 얼굴
작업 진행 상황은 확인할 수 있습니다.
