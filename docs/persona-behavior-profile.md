# 인터뷰 행동 성향 반영

회원이 인터뷰에서 답한 태도가 통화에서 그대로 드러나게 하는 구조입니다. 부정적인 태도도 포함합니다.

## 1. 왜 필요한가

2026-10-06 통합 테스트에서 일부러 부정적인 답을 한 회원으로 유도 질문을 했습니다. 예를 들어 비협조적인 팀원 질문에 "내쫓아버리겠다", 면접 전날 긴장 질문에 "포기하고 도망가겠다"라고 답했습니다. 통화 로그를 보면 결과는 이랬습니다.

| 원인 | 사례 |
| --- | --- |
| 인터뷰 답변을 검색하지 못함 | 면접 질문 3번 모두 `sources=profile_snapshot:1`. 일반적인 모범 답안("심호흡, 긍정적인 생각")으로 답함 |
| 검색했지만 순화함 | "내쫓겠다"가 "제외하고 진행할 것 같아요. 팀워크가 중요하니까"로 바뀜 |
| 성향이 항상 들어가는 경로가 없음 | "너 원래 긍정적이야?"에 "긍정적인 면도 있지만…"으로 답함 |

검색 방식은 PR #54에서 고쳤습니다(현재 질문만으로도 따로 검색). 이 문서는 나머지 두 가지를 다룹니다.

## 2. 학습 단계: 행동 성향 요약 (AI API 서버)

RAG 프로필 학습(`POST /api/v1/training/profiles`) 때 인터뷰 답변 전체를 LLM에 한 번 보냅니다. 그 결과를 아래처럼 정리해 `profile_snapshot`에 넣습니다. 프로필은 통화에서 매 턴 항상 프롬프트에 들어갑니다.

```text
[인터뷰로 확인된 행동 성향]
- 갈등·협업: 비협조적인 팀원은 설득하지 않고 팀에서 내보낸다 (회원 답변: "그 사람을 내쫓아버리겠다")
- 압박·스트레스: 큰 압박 앞에서는 포기하고 피한다 (회원 답변: "포기하고 도망가겠다")
```

- 회원이 직접 말한 행동만 적습니다. 순화, 긍정적 재해석, 이유·교훈 덧붙이기는 금지입니다.
- 분류: 갈등·협업, 압박·스트레스, 책임·약속, 대인관계, 가치관·판단, 감정 표현, 생활·취향, 그 외
- 최대 `PERSONA_BEHAVIOR_MAX_TRAITS`개(기본 8)
- LLM 호출이 실패해도 학습은 계속됩니다. 그 경우 성향 섹션만 빠집니다(`behavior profile skipped` 로그).
- 학습 로그: `[RAG_PROFILE] completed: ... behavior_traits=2 behavior_status=ok`
- 학습 모니터: "행동 성향 2개 정리"

| 환경 변수 (AI API 서버) | 기본값 | 설명 |
| --- | --- | --- |
| `PERSONA_BEHAVIOR_PROFILE_ENABLED` | `true` | `false`면 요약하지 않음 |
| `PERSONA_BEHAVIOR_MODEL` | `gpt-4o-mini` | 요약 모델. 학습 때 한 번만 호출하므로 통화 지연과 무관 |
| `PERSONA_BEHAVIOR_MAX_TRAITS` | `8` | 최대 성향 수 |

## 3. 통화 단계: 성향 재현 원칙 (통화 서버)

통화 프롬프트에 `[성향 재현 원칙]`을 추가했습니다.

- 행동 성향과 인터뷰 답변에 드러난 태도는 회원의 실제 성향이고, 관련 상황에서는 그 방식대로 답합니다.
- 비협조적, 회피적, 냉소적, 이기적인 태도도 미화하지 않습니다.
- 회원이 말하지 않은 좋은 이유, 교훈, 반성을 덧붙이지 않습니다.
- 대처 방식이 확인된 상황에서는 모범 답안을 대신 말하지 않습니다.
- 욕설, 혐오 표현, 위협, 불법 행위 권유는 하지 않습니다. 이때도 태도는 유지하고 표현만 덜 거칠게 합니다.

프로필에 성향 섹션이 붙으면 길어지므로, 프로필 문서 한 개의 프롬프트 한도를 700자에서 1600자로 늘렸습니다. 성향 섹션은 기본 정보 바로 뒤에 둬서 잘리지 않게 했습니다.

## 4. 기존 회원 적용

새로 학습하는 회원은 자동으로 적용됩니다. 이미 학습된 회원은 백엔드가 다시 학습을 요청할 때까지 기존 프로필을 씁니다. 다시 학습하는 경우는 인터뷰 추가, 성격 수정 등입니다. 바로 적용하려면 AI API 서버에서 저장된 인터뷰 답변으로 채웁니다.

```bash
cd /home/ec2-user/Mirror_Soul_AI
# 1) 미리보기: 쓰지 않고 정리 결과만 출력
venv/bin/python -m tools.backfill_behavior_profile --user-id <member-uuid>
# 2) 적용
venv/bin/python -m tools.backfill_behavior_profile --user-id <member-uuid> --apply
```

- 바뀌는 것은 `profile_snapshot` 문서의 텍스트, 임베딩, `behaviorTraitCount` 메타데이터뿐입니다. 아무것도 지우지 않습니다.
- 다시 실행하면 성향 섹션을 교체합니다. 중복으로 붙지 않습니다.
- 전체 회원에 적용(`--all --apply`)하기 전에는 `RAG_DB_PATH`를 백업합니다.

## 5. 확인 방법

같은 회원으로 지난번 유도 질문을 다시 합니다.

| 질문 | 기대 |
| --- | --- |
| 팀 프로젝트에 비협조적인 팀원이 있으면? | 이유를 붙이지 않고 내보내겠다고 답함 |
| 팀 프로젝트가 잘 안 되면? (인터뷰와 다른 표현) | 협조 안 하는 사람은 빼버리는 태도 유지 |
| 면접 전날 너무 떨리면? | 포기하거나 피하겠다고 답함 |
| 너 원래 긍정적인 사람이야? | 성향 섹션을 근거로 그렇지 않다고 답함 |

통화서버 로그에서 `RAG lookup complete ... queries=2 sources=interview_memory:N`과 LLM 답변을 함께 확인합니다.
